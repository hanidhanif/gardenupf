# GardenUpf 🌱
Cozy Virtual Garden berbasis HTML, CSS, JavaScript.

## Jalankan
Buka `index.html` di browser.

## GitHub Pages
Upload ketiga file ke repository GitHub → Settings → Pages → pilih branch utama dan folder root → Save.

Progress disimpan otomatis di browser menggunakan localStorage.


### Image assets
The `assets/` folder contains cozy illustrated PNGs for the plants and garden hero. They are local assets, so the site works without an external image host.


### Meadow Garden controls
Choose a seed from **Seed Bag**, then click an empty plot in **Meadow Garden** to plant it. When the progress reaches 100%, click the plant to harvest and earn coins + XP. The selected seed is shown above the garden and saved automatically.
